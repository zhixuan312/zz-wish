# Source17 painted timber contribution diagnosis

The native Source17 source, actual raw GLB and final decoded GLB keep the same red/teal paint factors, metalness 0, roughness factor 1, normal strength 0.119999997 and runtime minimum roughness 0.7. Native Principled uses IOR 1.5, specular IOR level 0.5 and no coat. Official KTX RGBA8 decoding finds actual delivered paint roughness green 0.8588–0.8706 versus raw 0.8549–0.8667. The delivery did not become smooth white plastic.

Detailed actual pairs and image hashes are in [round-1-snow-source17-paint-diagnosis.json](round-1-snow-source17-paint-diagnosis.json). The declared 256-pixel normal image reduces typical perturbation: with the actual 0.12 XY scale, median RGB-derived tilt is 0.192 degrees and 99th percentile 4.216 degrees, versus 0.248/8.999 degrees in the original image. This image-space calculation does not assert exact Blender/Three tangent-basis equivalence.

Runtime code adds fixture PointLights at actual source watts×40/(4π), once. They retain direct specular on baked static geometry while their direct diffuse is suppressed; they do not cast shadows. The visitor’s static visibility helper affects only the visitor point. Native beauty includes occluded glossy transport, while the maps contain diffuse transport. This is a real contribution difference. It is not yet established as the sole cause of the orange star-like patterns: low8 per-chart GI denoising/log sampling remains another possibility. The matching 1440 × 900 native reference is reported by Root to lack those patterns.

A new immutable-parent clone, `/tmp/one-light-snow17-c6-material-controls`, exposes reversible capture-only controls. Fixture-spec-off toggles actual fixture PointLight visibility, surviving intensity callbacks. Spec-off zeros direct and indirect static specular only after original material hooks; normal-off affects only painted normalScale. A separate preview-fill candidate aims the actual directional preview light from 1 m toward the actual cloth centre with a slight upward tilt and optional capture-camera following. Restore returns original hooks, cache keys, normals, fixture visibility and fill target. The old app, actual source, maps and main runtime remain untouched.

Only code parsing and a CPU Three-object/hook/arithmetic contract were executed. Real shader linking, exact-camera contribution images, C2 fill readability and final appearance remain Root-owned GPU gates. No source material, geometry, exposure or fixture watt tuning was adopted.

Actual follow-up: Root completed all three specular/normal controls with no errors or source changes. The stars persist, so those runtime contributions are rejected as the primary spatial cause. The [8/32 diffuse attribution](round-1-snow-source17-diffuse-variance.md) traces the pattern into the native raw night EXR and measures substantial sample variance. The earlier hypotheses above are retained as the pre-control record; higher-sample optical acceptance is still pending.
