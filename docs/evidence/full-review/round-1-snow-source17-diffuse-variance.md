# Source17 diffuse-star attribution and 32-sample diagnostic

The orange beam stars are present in the native **raw night EXR**, before per-chart OIDN or KTX compression. They persist in actual runtime fixture-specular-off, all-static-specular-off and painted-normal-off controls. All 38 selected screenshot rays matched actual Source17 prepared triangles and final decoded UV16/U8 data. The detailed evidence is [round-1-snow-source17-diffuse-variance.json](round-1-snow-source17-diffuse-variance.json).

Two pixels on the same carrying beam, 655/110 and 643/110, have the same effective red albedo 0.3834. Their 8-sample raw night red radiance is 0.008874 versus 0.001161; denoised values are 0.010309 versus 0.001656. The actual base-level KTX sampler remains strongly different after correct log interpolation. Lamp-bounce data contributes less than 0.5% at the selected beam locations. This rules out albedo/tint variation and added runtime specular as the primary spatial source. Compression changes some values, but does not originate the pattern.

The fresh same-source/same-UV hall-night32 bake completed on Metal/Metal OIDN in 46.49 seconds. All 57 frozen inputs stayed exact; physical transport fingerprint 5737206a… is unchanged. No GI pixels were reused. On the whole beam chart’s 2,096 core texels, raw high-pass standard deviation falls 51.5%; denoised high-pass standard deviation falls 25.7%. Raw 8/32 correlation is only 0.375, consistent with substantial sample variance. At the originally bright 462/91 sample, denoised red radiance falls 0.01077→0.001316; at 655/110 it falls 0.01031→0.001901.

The comparison is not clean convergence: the near column’s broad brightness remains and some samples grow. At 490/350, denoised red radiance rises 0.00562→0.00753. Peak points were chosen from the 8-sample image, so their regression alone is selection-biased; the report separately includes complete chart/core and interior high-pass statistics. A 32-sample image is not reference ground truth.

The paint graph, source/prepared geometry, UV0, tint and free normals retain their strict correspondence proofs. Actual source, prepared and baked meshes keep `UVMap` as active render UV; the UI-active bake layer becoming `Lightmap` is separate. No implicit Generated paint-albedo input or active-render-UV switch was found.

The official shared packer encodes only the new hall-night32 map with the existing UASTC2/RDO1/Zstd18 recipe. Actual 8 and 32 raw GLBs are byte-identical; only the exact measured geometry/material cache is reused. The encoder executes one map command and no geometry/material encoding. All actual source EXRs/PNGs and the original 8 package remain unchanged.
