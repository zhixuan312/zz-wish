## Contact and material gates

All **47 semantic contact groups** pass the literal gap ≤ 2 mm and penetration ≤ 5 mm guards on source, actual prepared triangles and the actual exported raw GLB. The inventory has 234 candidate meshes with no unregistered loose-prop candidate. Maximum source gap is 1.3025 mm; maximum penetration is 4.7500 mm. Unsaved +3 mm and −6 mm translations are rejected; matrices restore exactly. The actual pre-bake validator also passes all 19 genuine positive/negative cases. Fresh source bindings are retained for every source variant.

`audit_source_materials.py` exports and reads a real source GLB. It verifies the actual material factors, required COLOR_0, lacquer UV/normal/albedo channels, bronze roughness/metallic texture and pitting normal texture. Bronze is nonwhite in the GLB. The procedural material recipe emits reproducible image files; its result is not a native-only shader graph. These maps are project-authored data, not photographic scans. Supported `ShaderNodeMix` multiplication is used because the installed exporter drops legacy `MixRGB` factors.

The old hex helper incorrectly treated sRGB fractions as linear albedo: bronze was approximately `[.592,.439,.267]` rather than `[.309,.162,.058]`; oil was about 8.3 times too luminous by linear luminance. Authored CSS-like material hex now receives the inverse sRGB transfer once. Image color-space decoding, imported Poly Haven factors, linear patina multipliers, world/exposure/watts and explicitly linear light chromaticities are preserved. glTF factors are linear multipliers; image base colors are decoded before multiplication. See the [Khronos material specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#material-metallic-roughness).

The audit caught a real smooth-normal preparation error before any new GI was adopted. Independent triangle/parent association confirmed large snow changes. The corrected pipeline freezes actual evaluated float corner normals through join/triangulation, uses scoped eight-decimal normal extraction with restoration of the exporter default, and exports only standard attributes. Full source/prepared mapping passes at 1e−6 normal/UV/tint bounds; actual raw NORMAL is independently verified one-to-one across 322,414 triangles, maximum component error 1.79e−7. Failed/provisional studies remain ignored history.

There are seven measured static wick records: six lit fixtures and one out candle. Each record contains `lit`, `kind`, actual watts, actual `linearColor`, `wickTip`, point-light location/radius, object identifiers and support ownership. Runtime creates flames only for lit records and uses `wickTip` as flame origin. Smoke derives from actual rod tips. The runtime-owned visitor body is absent from source geometry; its attachment is `[-3.35, 3.22, 1.2]`, and the approved 45 W transport basis is `[-3.35, 2.80, 1.2]`.
