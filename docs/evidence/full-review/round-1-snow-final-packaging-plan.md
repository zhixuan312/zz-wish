# Snow explicit final packaging mode

`package-snow-compact-preview.py --final` is now a separate guarded path for actual future 64-sample-or-higher native maps. It omits the shared packer’s `--preview` flag and passes `--final` to the assembler. The default preview path remains unchanged. No full 64 bake or final delivery was executed.

The exact current code, real mode-guard evidence and invocation template are in [round-1-snow-final-packaging-plan.json](round-1-snow-final-packaging-plan.json). Source17’s executed preview recipe was byte-copied before these edits; its original package receipt and every delivered byte stay immutable. Both new final entry points reject the actual eight-sample Source17 maps before any output or encoder. Reassembling the default preview produces the exact original 21 file hashes, including its manifest.

Final mode requires all 16 genuine 64+ Metal/Metal maps, source/transport identity, 3 mips and 8 px gutters, fresh actualFACE/prune/precision proofs and all 47 literal contact/anchor checks. It retains declared camera normalization and indirect-only lamp quantity, requires native/ThreeWASM lossless Zstd verification, and fails an actual complete package above 15,000,000 bytes. The assembler validates real 64 provenance before clearing preview flags and checks that the native maps and decoded contacts share the actual source and receiver fingerprints.

The positive 64 path remains unexecuted until real approved 64 masters exist. Current success is code readiness, real LOW8 rejection and byte-exact default behavior; sample metadata has never been relabeled. All candidate paths remain ignored staging directories, with no public installation.
