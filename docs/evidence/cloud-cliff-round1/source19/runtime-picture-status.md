# Source19 runtime picture status

The fresh Source19 night and lamp surface maps were baked at eight fixed samples with Metal and Metal OIDN. The staged package plus live-density files is 8,031,238 bytes including its manifest. It is a partial preview; dusk/day and final-quality acceptance remain pending.

The first live frame exposed primary traversal truncation: broad parent bounds consumed the 256-step allowance before lower view rays reached the continuous cloud bank. Faster traversal through empty and tenuous spans restores coverage without changing authored geometry, density, lighting or surface maps.

The corrected actual Chrome pictures are in `artifacts/full-review/round-1/cloud19-picture-v2/`. The `desktop-night.png` and `phone-night.png` files are UI-free framebuffer captures from the existing Scene instance; `-ui.png` files include the form. Four close storm-lantern controls preserve normal, no-glass, no-wax and no-depth states. The normal close view shows a tapered SDF flame through the real glass. Its wide-view readability remains limited.

This preview is not visually accepted. Cloud lighting remains too smooth and endpoint edges show strata. The initial global 64-grid transport and 192-pixel radiance buffer are coarse approximations. A same-source 128×64×128 / 256-pixel candidate is staged for picture review. Near-light refinement, opaque-light visibility, temporal stability and actual phone frame rate remain open. No Source20, new bake, public install or final-quality claim is included.
