# Snow Roof Court seated stone figure

Printables creator dohnni published the 3D scan of an anonymous seated Buddha statuette as `Sitting Buddha statue` (model 720673) under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). The listing describes the source object as a statuette found by the photographer. The source photograph shows an ordinary seated figure with both hands joined in front. The model depicts no named temple, inscription or memorial. [Creator's original model and source photograph](https://www.printables.com/model/720673-sitting-buddha-statue) · [Creator's files](https://www.printables.com/model/720673-sitting-buddha-statue/files).

The original `Sitting_Buddha.stl` (file 3061998) was downloaded from Printables. The file is 8,042,184 bytes with SHA-256 `c9e5d5029478c231fbe605be33ad4ddc7b8f3f733d62de1677bbfcd5c8a3dea0`. The source scan supplies the statue's anatomy, including the face, both hands and the draped robe. The local derivative trims the uneven underside for a flat stone bearing, reduces the mesh with extra weight on the face, and fits the existing altar. Separate lightmap charts are derived from a smoothed copy for UV continuity. The delivered mesh retains the scan's relief.

The STL does not include colour. The grey vertex colour takes restrained mineral variation from the existing CC0 Poly Haven `stone_pavers` scan by Amal Kumar. Sampling in three orthogonal directions gives an even scale across the robe, hands and face. The material uses high roughness with zero metallic response. [Stone Pavers scan](https://polyhaven.com/a/stone_pavers) · [Poly Haven licensing](https://polyhaven.com/license).
